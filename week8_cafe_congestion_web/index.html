01

PROJECT

AI는 카페의 혼잡도를
어떻게 판단할까요?

Google Teachable Machine을 활용하여 카페 이미지를 학습시키고, 사진 속 환경을 세 가지 혼잡 상태로 구분하도록 모델을 만들었습니다.

☕
CLASS 01

여유

🪑
CLASS 02

보통

일정한 수의 손님과 빈 좌석이 함께 존재하는 상태입니다.

👥
CLASS 03

혼잡

많은 손님이 이용하고 있으며 빈 좌석이 적은 상태입니다.

02

TRAINING

이미지 데이터로
AI를 학습했습니다.

STEP 01

클래스 설정

여유, 보통, 혼잡의 세 가지 클래스로 카페 혼잡 상태의 기준을 설정했습니다.

STEP 02

이미지 수집

1차 학습에서는 각 클래스별 12장의 이미지를 사용하여 총 36장의 데이터로 모델을 학습했습니다.

STEP 03

모델 학습

Google Teachable Machine을 이용하여 코드를 직접 작성하지 않고 이미지 분류 모델을 학습했습니다.

STEP 04

새로운 데이터 테스트

학습에 사용하지 않은 새로운 카페 사진으로 모델의 예측 결과를 확인했습니다.

03

IMPROVEMENT

실패한 예측에서
개선 방법을 찾았습니다.

공간은 넓지만 손님이 많은 카페 사진을 테스트했을 때 AI가 실제 혼잡 상태를 보통으로 잘못 판단하는 문제가 발생했습니다.

개선 전 보통 99%

실제 상태는 혼잡

넓은 카페 공간 때문에 사진 속 빈 공간이 많이 보였고, AI는 해당 이미지를 보통 99%로 잘못 분류했습니다.

→
개선 후 혼잡 95%

혼잡으로 정상 분류

넓은 공간이면서 손님이 많은 혼잡 카페 사진 4장을 추가하여 다시 학습한 결과 같은 사진을 혼잡 95%로 올바르게 분류했습니다.

36 1차 학습 이미지
+4 추가 혼잡 이미지
99% 개선 전 오분류
95% 개선 후 혼잡 예측

KEY INSIGHT

데이터의 양보다 다양한 상황의 데이터가 중요했습니다.

이번 실습을 통해 AI 모델의 성능을 높이기 위해서는 단순히 이미지 개수만 늘리는 것이 아니라 다양한 환경과 상황을 학습 데이터에 포함하는 것이 중요하다는 점을 확인했습니다.
