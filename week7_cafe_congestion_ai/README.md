# 7주차 노코드 AI 모델 만들기

## 주제
카페 운영 효율화를 위한 좌석 혼잡도 분류 AI

## 사용 도구
Google Teachable Machine

## 클래스
- 여유
- 보통
- 혼잡

## 1차 학습 데이터
- 여유: 12장
- 보통: 12장
- 혼잡: 12장
- 총 36장

## 1차 테스트 결과
- 보통 사진 → 보통 98%
- 여유 사진 → 여유 80%
- 혼잡 사진 → 혼잡 88%
- 사람이 조금 있는 한산한 카페 → 여유 97%

## 오분류 사례
공간은 넓지만 손님이 많은 카페 사진을 테스트했을 때,
실제로는 혼잡으로 판단한 사진을 AI가 보통 99%로 분류하였다.

## 오분류 원인
카페 공간이 넓어 사진 전체에서 빈 공간이 많이 보였고,
기존 혼잡 학습 데이터에 넓은 카페의 혼잡 상황이 부족했던 것으로 판단하였다.

## 개선 방법
넓은 카페이면서 손님이 많은 혼잡 사진 4장을 추가하였다.

### 2차 학습 데이터
- 여유: 12장
- 보통: 12장
- 혼잡: 16장
- 총 40장

## 개선 전/후 결과 비교

| 구분 | 개선 전 | 개선 후 |
|---|---|---|
| 테스트 사진 실제 분류 | 혼잡 | 혼잡 |
| AI 예측 결과 | 보통 99% | 혼잡 95% |
| 분류 성공 여부 | 실패 | 성공 |

## 최종 결과
처음에는 넓은 공간의 혼잡한 카페 사진을 보통으로 잘못 분류했지만,
비슷한 형태의 혼잡 데이터를 추가하고 모델을 다시 학습한 결과
같은 사진을 혼잡 95%로 올바르게 분류하였다.

이를 통해 AI 모델의 성능을 높이기 위해서는 단순히 데이터 수만 늘리는 것이 아니라,
다양한 상황의 학습 데이터를 포함하는 것이 중요하다는 것을 확인하였다.

## 모델 내보내기
Teachable Machine의 모델 내보내기 기능을 확인하였다.

지원 형식:
- TensorFlow.js
- TensorFlow
